# OWASP ZAP Dynamic Application Security Testing
 
Tool:
OWASP ZAP Baseline Scan
 
Target:
http://localhost:8888
 
Method:
Baseline dynamic analysis against the locally deployed educational crAPI environment.
 
Pipeline Stage:
DAST
 
Purpose:
Identify runtime security weaknesses that may not be visible through SAST or dependency scanning.
 
Security Value:
Provides behavioural analysis of the running application and supports security-gate decisions.
 
Result:
OWASP ZAP generated a security report containing runtime findings that were reviewed as part of the DevSecOps assessment.
